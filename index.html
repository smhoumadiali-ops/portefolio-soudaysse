Connexion GitHub

Nécessaire pour que les modifications soient réellement enregistrées sur ton site. Ton jeton n'est jamais écrit dans le code — il reste seulement dans cet onglet et disparaît quand tu le fermes.

Créer un jeton : github.com → Settings → Developer settings → Personal access tokens → Fine-grained tokens → limite-le à ce seul dépôt, permission "Contents: Read and write" uniquement.
